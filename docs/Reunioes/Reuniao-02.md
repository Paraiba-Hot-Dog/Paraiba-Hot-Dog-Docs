
# Ata de Reuniao 02

## Objetivo

Segunda reuniao focada em organizar as Historias de Usuario (US) que o grupo tinha em mente, alinhando o escopo com as recomendacoes do professor.

## Recomendacoes do professor

- Adotar abordagem mobile first
- Permitir anotacao de pedidos com atualizacao automatica dos graficos
- Criar uma pagina dedicada ao BI
- Desenvolver um prototipo de alta qualidade no Figma
- Definir ate 15 US, com ate 5 requisitos por US
- Selecionar o maximo de requisitos possivel ate segunda-feira

## Definicoes da reuniao

- Iniciar a estruturacao das US priorizando funcionalidades essenciais
- Relacionar requisitos por US para facilitar o planejamento do backlog
- Manter foco em funcionalidades que gerem dados para a pagina de BI
